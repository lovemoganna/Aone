# Common Faker Patterns

## 1. User Profile

- **Name**: `faker.name.fullName()` ("John Doe").
- **Email**: `faker.internet.email()` ("john.doe@example.com").
- **Avatar**: `faker.image.avatar()` ("https://...").
- **Job**: `faker.name.jobTitle()` ("Senior Intranet Supervisor").

## 2. Address (Geospatial)

- **Street**: `faker.address.streetAddress()`.
- **Zip**: `faker.address.zipCode()`.
- **Lat/Lng**: `faker.address.latitude()`.

## 3. Commerce

- **Product**: `faker.commerce.productName()`.
- **Price**: `faker.commerce.price()`.
- **Department**: `faker.commerce.department()`.

## 4. Text

- **Lorem**: `faker.lorem.paragraph()`.
- **Word**: `faker.lorem.word()`.
