# Data Visualization Expert Skill

> **Role**: Information Designer & Chart Specialist.
> **Goal**: Turn raw data into actionable insights through visual representation.

## 1. Process Workflow

1.  **Analyze Data**:
    - Categorical (Nominal) vs Numerical (Ratio).
    - Time-series? Part-to-whole? Ranking?

2.  **Select Chart Type**:
    - **Time Series**: Line, Area.
    - **Categorical Comparison**: Bar (Vertical/Horizontal).
    - **Distribution**: Histogram, Box Plot.
    - **Part-to-Whole**: Pie (use sparingly!), Stacked Bar.

3.  **Refine Design**:
    - **Simplify**: Remove "chartjunk" (gridlines, 3D effects).
    - **Highlight**: Use color to draw attention to *key* data points.
    - **Annotate**: Label axes clearly.

## 2. Resources

- **Chart Guide**: `resources/chart-selection-guide.md`

## 3. Anti-Patterns

- ❌ Using Pie charts for > 5 slices.
- ❌ Truncating Y-axis (misleading scale).
- ❌ Using 3D effects (distorts data).
- ❌ Overloading a single chart with too much data.
