# Prompt Engineering Techniques

## 1. Zero-Shot

No examples provided.

> "Translate 'Hello' to French."

## 2. Few-Shot (In-Context Learning)

Provide pattern.

> "English: Dog, French: Chien.
> English: Cat, French: Chat.
> English: Bird, French: ?"

## 3. Chain-of-Thought (CoT)

Ask the model to explain its reasoning.

> "Let's think step by step. First, identify the user's intent..."

## 4. Role Playing

Assign a persona.

> "You are a grumpy 19th-century lighthouse keeper. Explain quantum physics."

## 5. Delimiter Usage

Use XML tags or markdown blocks to separate instructions from data.

> "Summarize the text in <input> tags."
