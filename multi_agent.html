Ollama CORS 配置指南

由于浏览器安全策略，需要配置 Ollama 允许跨域请求。请按照以下步骤操作：

1 停止当前运行的 Ollama
2 选择你的操作系统，使用对应命令启动
OLLAMA_ORIGINS=* ollama serve

或者设置为永久环境变量：

launchctl setenv OLLAMA_ORIGINS "*"
OLLAMA_ORIGINS=* ollama serve

如果使用 systemd 服务，编辑配置：

sudo systemctl edit ollama.service

添加以下内容：

[Service]
Environment="OLLAMA_ORIGINS=*"

然后重启服务：

sudo systemctl daemon-reload && sudo systemctl restart ollama

方法一：在命令提示符中运行

set OLLAMA_ORIGINS=* && ollama serve

方法二：设置系统环境变量（永久生效）

setx OLLAMA_ORIGINS "*"

然后重启 Ollama 服务。

docker run -d -e OLLAMA_ORIGINS=* -p 11434:11434 ollama/ollama
3 回到本页面，点击"刷新模型"重试
如果你使用的是远程服务器上的 Ollama，请确保将 OLLAMA_HOST 设置为 0.0.0.0 以允许外部连接。
